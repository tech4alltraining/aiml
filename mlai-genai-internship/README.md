# ML/AI & GenAI Internship Program

This folder has two doors. Take the one that applies to you.

| | |
|---|---|
| 🎓 **[student/](student/)** | Everything you need to learn from — handbook, notebooks, apps, exercises, setup, troubleshooting |
| 🧑‍🏫 **[trainer/](trainer/)** | Everything needed to deliver it — teaching sequence, facilitation notes, slide decks |

---

## Students start here

```text
student/
├── README.md                    start here
├── setup-guide.md               install Python and the packages
├── sessions/                    THE COURSE — twelve sessions, in order
├── notebooks/                   run these — one per session, Colab or local
├── exercises-assignments.md     practice and graded assignments
├── troubleshooting.md           every error and its fix
├── prompts.md                   copy-paste prompt library
├── requirements.txt
├── student-handbook.md          reference book (module-based, supplementary)
└── tutorials/
    ├── apps/                    build something
    └── concepts/                read about something
```

**Never written Python?** [Session 1](student/sessions/session-01-python-refresher.md) starts from `print()` and assumes nothing.

## Trainers start here

```text
trainer/
├── README.md                    start here
├── session-plan.md              the teaching sequence
├── curriculum.md                topic coverage with every link
├── activities.md                facilitation notes for class activities
├── latex/                       six projector-ready slide decks
└── archive/                     superseded versions
```

The activity numbers in `trainer/` match the student handbook exactly, so you can call out "Activity 2.5" and everyone is on the same page.
